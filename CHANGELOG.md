# Changelog

All notable changes to Forever Classic UI are documented here.

## [0.1.0] - Unreleased

### Added
- Classic gryphon end caps on the main action bar, mirrored from the single 1.x art file as the old bar did.
- The original stone bar band drawn behind the main bar, micro menu and bag bar, sized to whatever sits on that row.
- Classic button style: square slot borders, the old pressed and highlight art, red attack flash and the equipped-item border, with optional square icons.
- Classic stone page arrows for action bar paging.
- Options panel and `/fcui` commands with per-feature toggles, a texture source switch (client files or bundled copies) and `/fcui debug` for bug reports.
